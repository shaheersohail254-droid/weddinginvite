# Arham & Umaima — Digital Wedding Invitation

Traditional Pakistani / Mughal-inspired Next.js wedding invitation.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Build for Vercel

Push this folder to GitHub and import the repository into Vercel. Vercel will detect Next.js automatically.

## Music

Place your licensed wedding/background music file at:

`public/music/wedding-music.mp3`

The invitation attempts to start music after the guest clicks **Open Invitation**. The music button remains available at the bottom-right.

## AI wedding visuals

The three event cards currently contain CSS-based faceless Pakistani wedding placeholders so the site is fully functional without external images. Replace them later with AI-generated images in `public/images/` if desired.
